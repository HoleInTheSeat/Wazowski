# Documentation screenshots

Drop screenshots referenced by the docs into this folder, using the exact
filenames below so the existing `![...](images/NAME.png)` links resolve.

PNG is preferred. A window-sized capture (not full-screen) reads best; crop to
the relevant area where noted.

| Filename | What to capture |
|---|---|
| `main-window.png` | The whole Wazowski window with a session or two in the tree and a terminal open. Used on the front page. |
| `sessions-pane.png` | The left **Sessions** pane: a few folders (some collapsed), a couple of sessions, and the serial dock button at the bottom. |
| `new-ssh-session.png` / `new-rdp-session.png` / `new-vnc-session.png` | The **New session** dialog for each type, showing the type picker and fields. |
| `icon-picker.png` | The icon/color picker (grid of icons recoloring live). |
| `terminal-split.png` | One tab split into two panes, ideally with **broadcast** armed (the broadcast indicator visible). |
| `ssh-sftp.png` | An open SSH terminal tab with the **Files** (SFTP) pane beside it. |
| `rdp-session.png` | A native RDP session in a tab, with the remote-ops toolbar (screenshot / paste / Ctrl+Alt+Del / Windows key) visible. |
| `vnc-session.png` | A native VNC session in a tab. |
| `serial-menu.png` | The **Serial connections** button at the bottom of the Sessions pane with its menu open (USB / Bluetooth / … submenus). |
| `vault.png` | The **Vault** pane listing a couple of named credentials. |
| `add-source.png` | The **Add shared source** dialog, showing a git repo with the Description field. |
| `macros.png` | The **Macros** pane and/or the macro editor dialog. |
| `quick-servers.png` | **Tools → Quick servers** with a server configured (and ideally running, showing its log). |
| `tools-json.png` | The **JSON/jq puller** with a URL, a jq filter, and output. |
| `tools-ip.png` | The **IP address viewer** — redact the public IP and domain. |
| `settings-backup.png` | **Settings → Backup** with the Export/Import buttons. |

You can add more and reference them from the relevant page; keep names
lowercase-with-hyphens.
